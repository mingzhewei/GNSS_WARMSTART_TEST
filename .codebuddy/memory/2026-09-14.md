## 结论
- 室内冷启动慢的主因 = "待在室内收不到星"的等待段：无解段 83.2s / 34.8s，段内跟踪星均值仅 0.2 / 0.4 颗，占室内"开始→首固定"的 62.5% / 30.5%；到开阔处后时间→单点仅 3.2/3.8s
- 速度佐证（INSPVAXA，仅用于解释）：室外全程 0 m/s 静止；室内两份在星数爬升的同时出现 1–3 m/s 运动，160s 后回落到 ~0.05 m/s → 即"室内冷启动后携带到测试点"
- indoor_02 浮点 41.2s 早于 FINESTEERING 48.4s（COARSE 段内），再次验证精时标非 RTK 前置条件
- 差分可用时刻紧随观测可用时刻（室外 12.4s / 室内 90.0s、35.0s），与"是否已能收星"强相关
